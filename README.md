# Turbo Ilha (versão PC)

1. Clique em **TurboIlha_jogo.zip** e depois em **Download** (ou "View raw").
2. Clique com o botão direito no zip baixado e escolha **Extrair tudo**.
3. Abra a pasta TurboIlha e dê dois cliques em **TurboIlha.exe**.

Controles: veja o menu do jogo. Para controles genéricos (ex.: Razer Serval), use "Configurar controle".
