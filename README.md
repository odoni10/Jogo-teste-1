# Turbo Ilha (versão PC)

## [>> CLIQUE AQUI PARA BAIXAR O JOGO (142 MB) <<](https://github.com/odoni10/Jogo-teste-1/raw/main/TurboIlha_jogo.zip)

Não use o botão verde "Code > Download ZIP": ele não traz o jogo.

1. Baixe pelo link acima.
2. Clique com o botão direito no zip baixado e escolha **Extrair tudo**.
3. Abra a pasta TurboIlha e dê dois cliques em **TurboIlha.exe**.

Controles genéricos (ex.: Razer Serval): use "Configurar controle" no menu.
